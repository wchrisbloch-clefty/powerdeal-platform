# Deal Qualification Scorecard

Win or lose fast. Never carry a bad deal — it crowds out real ones.

## Section 1 — ICP Score (25 points)

Score 1–5 on each dimension. Pursue threshold: 15/25.

| Dimension | Score (1–5) | Evidence / Rationale |
|---|---|---|
| **Power need** — 5+ MW baseload continuous process | | |
| **Grid pain** — queue 3+ yrs, no access, or constrained | | |
| **Permitting pressure** — non-attainment or NOx-constrained | | |
| **ESG/regulatory driver** — public targets, SEC, hyperscaler mandate | | |
| **Financial capacity** — investment-grade, active capex, or PPA-ready | | |
| **ICP Total** | **/25** | |

**ICP Verdict:**
- 20–25: Strong ICP — pursue aggressively
- 15–19: Workable — pursue with defined qualification milestones
- 10–14: Borderline — only pursue if a specific condition is met (name it)
- <10: No-go — park in nurture or disqualify

## Section 5 — Final Score and Recommendation

| Section | Score | Max |
|---|---|---|
| ICP | | 25 |
| Deal Mechanics | | 20 |
| Competitive | | 10 |
| Vertical Fit Bonus | | 5 |
| **TOTAL** | | **60** |

**Recommendation:**
- 45–60: **Pursue — Tier 1.** Dedicate BD/AE, monthly strategy review, full account plan.
- 30–44: **Pursue — Tier 2.** Shared BD/AE, quarterly review, defined next gate.
- 20–29: **Conditional.** Define the one thing that must be true to escalate. Set a 60-day checkpoint.
- <20: **No-go.** Park in nurture or disqualify. Capture the reason.
